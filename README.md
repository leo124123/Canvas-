# Canvas — Presentación Interactiva de Computación & Inteligencia Artificial

Plataforma web interactiva para presentaciones académicas sobre **Inteligencia Artificial** y **Computación en la Educación y Humanidades**.

## 🚀 Características
- **Efectos 3D y Tarjetas Flotantes**: Interfaz inmersiva con animaciones de física, giroscopio y sombras dinámicas.
- **Fondos Animados Cinemáticos**: Cuarto de servidores cyberpunk, lluvia de datos y terminales inteligentes.
- **Simuladores Interactivos en Vivo**:
  - 🔍 **Reconocimiento Facial**: Escaneo biométrico TrueDepth con retícula y puntos 3D.
  - 🛡️ **Filtros y Detección de Fraude**: Simuladores en vivo de recomendaciones, anti-spam y bloqueo de anomalías bancarias.
  - 🤖 **IA Generativa**: Consola de código streaming (typewriter), difusión de imágenes y síntesis de voz.
  - 🧠 **Matriz Cognitiva AGI**: Núcleo sináptico multidisiciplinario interconectado.
- **Efectos de Sonido Cinemáticos**: Síntesis de audio con Web Audio API para navegación y clics.

## 🛠️ Tecnologías
- **React 19**
- **TypeScript**
- **Vite**
- **Lucide Icons**
- **Canvas-Confetti**

## 💻 Instalación y Uso Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
